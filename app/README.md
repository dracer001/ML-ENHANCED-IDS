## App 1 — ids_classic.py (Rule-Based, No ML)

Detects threats using behavioral thresholds:
- Port scan (>15 distinct ports probed from one IP)
- SYN flood / DDoS (>50 SYN packets/sec from one IP)
- Brute force (>10 rapid connection attempts to same port)
- ICMP flood (>30 ICMP packets/sec)
- DNS flood / exfiltration (>100 DNS queries/min)
- ARP poisoning (IP-to-MAC mapping change)
- Data exfiltration (>5MB outbound to external unknown IP)

### Commands

```bash
# List interfaces
python ids_classic.py list

# Start — host only (v1)
python ids_classic.py start --iface "\Device\NPF_{YOUR-GUID}" --email-to you@example.com

# Start — network-wide promiscuous (v2)
python ids_classic.py start --iface "\Device\NPF_{YOUR-GUID}" --network --email-to you@example.com

# Replay a saved PCAP file
python ids_classic.py start --pcap captures/attack.pcap --email-to you@example.com

# Test email (verify SMTP works)
python ids_classic.py test-email --email-to you@example.com

# Export last 24h events to CSV + print stats
python ids_classic.py report --hours 24 --stats

# Run without sending emails (for testing)
python ids_classic.py start --iface "..." --dry-run
```

## App 2 — ids_ai.py (ML-Enhanced)

Uses trained ML/DL models to classify every network flow.

### Available Models

| Flag | Model | Accuracy | FPR | Speed |
|------|-------|----------|-----|-------|
| `xgboost` (default) | XGBoost | 99.88% | 0.015% | 0.16ms/flow |
| `rf` | Random Forest | 99.26% | 0.05% | 0.3ms/flow |
| `cnn` | 1D CNN | 77.65% | best cross-dataset | 2ms/flow |
| `lstm` | LSTM | 77.48% | good temporal | 3ms/flow |
| `all` | All 4 models | best coverage | email lists which caught it | slower |

### Commands

```bash
# List interfaces
python ids_ai.py list

# Check which model files are present
python ids_ai.py models

# Start with default model (xgboost), host-only
python ids_ai.py start --iface "\Device\NPF_{YOUR-GUID}" --email-to you@example.com

# Start network-wide with LSTM
python ids_ai.py start --iface "\Device\NPF_{YOUR-GUID}" --network --model lstm

# Start with ALL models — email shows which ones caught the attack
python ids_ai.py start --iface "\Device\NPF_{YOUR-GUID}" --model all --email-to you@example.com

# Lower confidence threshold (more sensitive, more false positives)
python ids_ai.py start --iface "..." --model xgboost --threshold 0.5

# Replay PCAP with CNN model
python ids_ai.py start --pcap captures/attack.pcap --model cnn

# Replay PCAP with all models
python ids_ai.py start --pcap captures/attack.pcap --model all --email-to you@example.com

# Test email
python ids_ai.py test-email --email-to you@example.com

# Export report
python ids_ai.py report --hours 24 --stats

# Run without emails (testing/demo)
python ids_ai.py start --iface "..." --dry-run --model all
```

## Email Alert Format

When a threat is detected, you receive:
- Subject: `[IDS ALERT] <Attack Type> detected from <IP>`
- Source IP, destination IP, attack type, confidence score
- Flow statistics (packets, bytes, duration, protocol)
- Which model(s) detected it (when using --model all)
- HTML and plain-text versions

## SMTP Password Note

The sender password is NOT hardcoded in the scripts for security.
Set it using one of:
1. Environment variable: `set IDS_EMAIL_PASS=password` (Windows CMD)
2. CLI flag: `--email-pass password`
3. Edit `DEFAULT_PASSWORD` in `core/alerter.py` for permanent setup

## Running as Administrator

Promiscuous mode (--network / v2) and raw socket capture on Windows
requires the terminal to be run as Administrator:

1. Right-click PowerShell or CMD
2. "Run as administrator"
3. Navigate to the ids_app folder and run commands as normal
